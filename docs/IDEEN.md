# Ideen für später

- **Übertragen mit Auswahl:** Statt „auf alle Spuren“ nur „Farbe übertragen“ / „Helligkeit übertragen“ und vorn an den Spuren Häkchen setzen, welche Spuren übernehmen bzw. synchron bleiben. Erleichtert komplexe, exakte Sets.
- **Raumkarte:** Einfache Karte je Raum, auf der Leuchten verortet werden. Daraus entstehen wandernde Muster (Wellen, Lauflichter) ohne manuelles Sortieren.
- **Wohnungskarte:** Dasselbe für die ganze Wohnung, Räume als Flächen.
- **Start/Stopp in anderen Dashboards:** Eigene kleine Kachel bzw. Taste je Ablauf (Start, Pause, sanft stoppen, Laufanzeige). Übergangsweise geht das schon mit Bordmitteln: Kachel-Karte mit dem Skript `script.fade_studio_…` (Tippen startet; während des Laufs stoppt Tippen hart).
